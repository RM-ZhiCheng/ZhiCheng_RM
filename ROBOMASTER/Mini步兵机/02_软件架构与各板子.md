# Mini 步兵 · 软件架构（FreeRTOS + HAL）

> 7 块 STM32 板子各跑一份 FreeRTOS 固件，分布式协同。主程序在各自 `main.c`。

## 一、7 个模块

| 模块 | 主控 | 时钟 | 干什么 |
|------|------|-----|--------|
| 00 遥控器 | STM32F103 | 72MHz | ADC 摇杆/旋钮、编码器、OLED，NRF24L01 无线发射 |
| 01 底盘主控 | STM32F407 | 168MHz | 全向轮，电机 PID + PWM(10kHz)，BMI055 IMU 姿态，无线收遥控 |
| 02 云台主控 | STM32F407 | 168MHz | BMI055+IST8310 IMU、PID、低通滤波、WS2812 灯条、激光 |
| 03 灯条主控 | STM32F103 | 72MHz | 驱动 WS2812 灯条，红/蓝切换**连续两帧匹配去抖** |
| 04 发射机构 | STM32F103 | 72MHz | 摩擦轮 + 扳机(Biu) PWM、DMA、无线 |
| 07 pitch_4310 | STM32F103 | 72MHz | FOC 三环驱动 pitch 电机（4310），AS5600、INA240 电流 |
| 08 yaw_4310 | STM32F103 | 72MHz | FOC 三环驱动 yaw 电机；**上电等待底盘发有效遥控才通电** |

## 二、通信

- **NRF24L01 无线**：遥控器 ↔ 底盘/云台，以及各执行板间。
- **CAN**：裁判系统 / 板间。
- **UART(DMA)**：传角度/调试输出（如 `send_angal` 用 UART DMA）。

## 三、控制与算法

- **电机三环 PID**：位置环 → 速度环 → 电流环。云台板提供 `PID_Pos/Vel/Cur_Set`，pitch 与 yaw 参数不同。
  - pitch：`Pos 1.0 / Vel 0.01 / Cur 0.5`
  - yaw：`Pos 0.60 / Vel 0.002 / Cur 0.5`（负载云台，低启动扭矩，明显为抑制摆振+防过流调校）
- **FOC 磁场定向控制**：新 FOC 板(drv8313) + 4310 无刷，配 AS5600 角度、INA240 相电流、Lowpass 低通。
- **IMU 姿态融合**：BMI055（加计+陀螺）+ IST8310（磁力计）。
- **WS2812 灯条去抖**：`stable_packet_count>=2` 才切色，防无线瞬间抖动致蓝灯闪红（很专业）。
- **发射**：摩擦轮(1503/520) + 发射电机双 PWM。

## 四、值得学的点

1. 分体式多板协同时，如何用无线/CAN 把「输入-决策-执行」串起来。
2. 云台 yaw 的 FOC 三环调参思路（看 `main.c` 里那几组 `PID_xxx_Set`）。
3. WS2812 灯条颜色的软件去抖逻辑。
4. `main.c` 里演示了 `sys_stm32_clock_init` 不同主频（F1=72M / F4=168M）的差异。
