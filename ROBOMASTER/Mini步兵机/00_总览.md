# Mini 步兵机器人 · 方案总览

> 项目名：**蓝三步兵（Mini）**
> 定位：RoboMaster 步兵机器人整机方案（战队复刻版）
> 来源：`C:\Users\ASUS\Desktop\大学\ROBOMASTER\Mini (2)\Mini`

## 一句话

一台**步兵类机器人**的「硬件 + 软件」全套资料：11 块 PCB、一套 SolidWorks 3D 模型、一套 28 页装配手册、一份 BOM 采购清单，以及 **7 块 STM32 分体式 FreeRTOS 固件**。

## 顶层结构

```
Mini/
├── 软件/
│   ├── New_rtos版本/freertos/     ← 7 个 STM32 固件工程
│   ├── 蓝三步兵BOM.xlsx           ← 采购清单（13 张表）
│   └── 装配手册.pdf               ← 28 页，10 部装配
└── 硬件/
    ├── 01.硬件PCB/                ← 11 个立创EDA PCB 工程
    └── 02.3D建模/                 ← SolidWorks 模型（全带 .step）
```

## 与学习的关系

这套工程是「**视觉 + 云台联动 + 底盘 + 灯条 + 无线**」的完整参考，非常适合用来对照学 RoboMaster 电控/协同。云台 yaw 被反复调试（工程里留了一堆 build 日志），是整机难点与精华。

## 重要说明

- 原始工程文件（PCB/3D/固件）为二进制，量大，保留在桌面 `Mini (2)` 文件夹作为**原始资料**；本目录是其**整理后的分类笔记**。
- 云台 yaw / pitch 两个 FOC 子板：实际控制源码（`pid / foc_control / motor / as5600` 等）已不在工程里，只剩编译产物 + `main.c`。
