# Mini 步兵 · 装配手册（28 页 / 10 步）

> 来源：`装配手册.pdf`。全程以图片 + 零件清单呈现。

## 装配流程

1. **全向轮**：TPU85 滚子（可打印）+ M2x8 平头+防松螺母 + M3x20 销柱 + 止血带。
2. **轮组**：520 编码器电机 + 车体/电机连接件 + 连轴×4 + 挡板×4 + 1.5x18x80 压簧；滚花螺母热插进孔位，压簧+销柱组成悬挂。
3. **底盘预装**：轮组×4 + 底板×2 + 护圈1×4。
4. **装甲板**：装甲板外板 + 装甲板 + 传感器 + 护圈2 + 微动开环（微动开关轻轻一碰即触发击打检测）。
5. **Yaw 上板**：yaw 电机连接 + 滚珠轴承内/外圈 + 底盘上板 + FOC 控制板 + 6mm 弹丸（轴承润滑/检测）+ m2.5x5/m3x16/m3x25 紧固。
6. **底盘总装**：预装底盘 + Yaw上板 + 装甲板×4 + 护圈3×4。
7. **Pitch 轴**。
8. **发射机构**：摩擦轮 + 发射电机。
9. **枪口**。
10. **云台总装**。

## 要点

- 大量使用**热插滚花螺母**（注：烫完拿小棍捅一下，防止耗材融进螺母里）。
- 紧固顺序建议：先轻后紧、四处对称，保证装甲板/云台不歪斜。
- 云台 yaw/pitch 的轴承、传动是装配精度关键。
